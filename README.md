## Daftar fitur
- 4 halaman: Beranda, Tentang, Katalog, Kontak, dengan navigasi yang sama di semua halaman
- Elemen semantik: header, nav, main, section, article, footer
- Tabel harga (katalog) dan tabel jam operasional (kontak) dengan thead dan tbody
- Formulir kontak dengan label terhubung, required, type email, type tel + pattern, minlength/maxlength
- Satu file CSS eksternal: flexbox (navigasi), grid (katalog), 8 variabel CSS, efek hover, transition, @keyframes
- Responsif: media query <= 600 px dan >= 992 px
- Bonus JavaScript: menu hamburger, validasi formulir dengan pesan di bawah kolom, cari/filter/urut katalog
